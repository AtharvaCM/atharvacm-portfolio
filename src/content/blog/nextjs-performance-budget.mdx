If your portfolio feels premium but loads slowly, it is not premium. Start with budgets:

- JavaScript route budget per page.
- LCP budget for hero section assets.
- CLS budget for dynamic modules.

## Baseline recommendations
Use image sizing discipline, avoid unnecessary client components, and defer non-critical scripts.
